# Behavior-focused test consolidation

This owner-reviewed acceptance-contract revision consolidates existing checks at baseline `5c9756bb0bd132cb15251c4243b17deb7263e2a1`. It changes test organization and assertion scope, not product behavior. Its activation requires independent coverage review, fresh complete verification, source-bound code review and verified integration.

The revision removes two request-only browser cases and one historical delivery-material Node case. The baseline inventory changes from 280 Node and 68 browser cases to 279 Node and 66 browser cases before any separately added harness regressions. Test count is an accounting result, not the optimization target. Full and critical verification commands, the 17 required browser identities, all 73 critical Node identities and all six critical browser identities remain unchanged.

## Shared diagnostic setup

`acceptance/diagnostic-fixture.ts` now owns the repeated insertion of a persisted job/run pair, status translation, timestamps and evidence-directory creation used by the history, lifecycle and read-only browser fixtures. Each test file still owns its specific issue/requirement setup, reports, retained evidence content, expectations and cleanup. The helper cannot claim execution, verification or merge authority; it creates disposable inspection fixtures only.

No duplicate lifecycle keyboard, narrow-screen, injection, immutable evidence, failure recovery or target-safety checks are removed in this revision. Their necessity can be reviewed separately with specific replacement coverage. This deliberately avoids treating superficially similar scenarios as proven duplicates.
