# Browsing requirement delivery

Select an enrolled repository in the sidebar, then choose **Requirements**. The list shows ten requirements per page, ordered by creation time and then identity, newest first. Select a title to inspect the original business goal, conversation provenance, owned child issues, and delivery progress. Opening child diagnostics retains the requirement context; closing the dialog restores focus to its opener.

Recorded status, child integration, whole-goal acceptance, and final delivery are separate observations. Acceptance requires the latest owned whole-goal verification job to be completed with its exact matching passed, completed run. A historical pass or a Done label cannot replace that evidence. Final delivery also requires at least one child and recorded merges for every child. A requirement's own publication snapshot determines its GitHub enrollment; GitHub delivery additionally requires that snapshot to record merged publication. A requirement without a publication snapshot remains local-only even if its repository is later enrolled for GitHub delivery. Local-only requirements say so explicitly.

Current blockers reflect the latest owned stage and child attempts, excluding recovered failures. A publication reason is current only while publication is blocked. Use the stage-run selector to inspect historical reports and their manifest-listed evidence through the existing readers, including requirements without children. Historical reports retain their own results without changing current acceptance or delivery.

Background refresh retains the current page, selection, and focus. If refresh moves a focused requirement opener off the current page, focus moves to the retained selected inspection heading. Other focused controls retain focus. **Refresh repositories** reloads repository and child metadata; report and evidence errors have their own read retry controls. Switching repositories clears requirement selection and pending report readers. This subview offers inspection only and sends no execution or mutation requests.
