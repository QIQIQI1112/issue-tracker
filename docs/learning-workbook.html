How to work through this lab
  1. Start with assignment 01. Work at your own pace; the time estimates are guides.
  2. Write your prediction before asking AI to explain it. Then compare the explanation with the code and observed behavior.
  3. Use AI as a tutor for 01–04. In 05, you can write the implementation yourself or direct an agent, but you own the contract and evidence.
  4. Include file/function names, commands, actual results, and evidence paths. “It works” is not an answer.
  5. Mark an assignment ready when you can explain your answers. Export that assignment's answers and ask for review before moving on if you want feedback.
